Nobel Prize Data Analyzer 🏆

[nobelpic](https://github.com/user-attachments/assets/418bcfa5-4dd3-497b-bcba-4adad7f47ce3)


A Python-based GUI application for analyzing Nobel Prize laureates data with interactive visualizations and search capabilities.



Features ✨
Laureate Search: Find Nobel winners by name with detailed biographical information
- Interactive Visualizations:
  - Proportion of USA-born winners over decades
  - Female winner trends by category
  - Age distribution patterns over time
  - Top 10 countries by prizes
  - Country distribution pie chart
- GUI Interface: User-friendly Tkinter-based interface
- Data Validation: Handles missing columns and data inconsistencies
- Image Display: Shows Nobel-related imagery in the interface


Installation 🛠️

Requirements
- Python 3.6+
- Nobel Prize dataset (CSV)
- Required Python packages:

bash
- pip install pandas numpy matplotlib seaborn pillow

Usage 🚀
Search Function:
- Enter full or partial name in search box
- View biographical details in pop-up window

Data Visualization:
- Select plot type from dropdown menu
- Click "Show Plot" to generate visualization
- Interactive matplotlib figures with professional styling

Supported Visualizations:
- Line charts for demographic trends
- Regression plots for age analysis
- Bar charts for country rankings
- Pie charts for geographical distribution

Dependencies 📦
- Package	Purpose
- Pandas	Data manipulation
- Matplotlib	Visualization core
- Seaborn	Statistical visualizations
- Tkinter	GUI interface
- Pillow	Image handling
